# el-nino-ghg-dashboard

## Editing
Change the dashboard by editing `src/page.html` (code) or the small site lists in `data/`; the **Build page** workflow rebuilds and publishes the generated `dashboard-single.html` and `index.html`. See `build/README.md`.

## How this was made
